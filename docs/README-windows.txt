GETTING STARTED
1. Extract the whole zip file to a folder of your choice.
2. Start the program (.exe). Nothing needs to be installed.
3. Keep WebView2Loader.dll in the same folder. It is a small file from Microsoft
   that the programs use to show their window.
4. Click "Help" in the program for the full guide (it opens in your browser and
   also works without internet).

The first time, Windows may show "Windows protected your PC" because the programs
are not signed with a paid certificate. Click "More info" and then "Run anyway".
